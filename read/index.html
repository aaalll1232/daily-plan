② 转化 5 分钟：把别人的话变成自己的

示范一｜原句：怕问题，问题就会成为“拦路虎”；敢碰硬，问题就会变成“垫脚石”。

  • 我的改写：同一件事，绕着走它就是绊脚石，迎上去它就是登高台。矛盾本身不决定成败，对待矛盾的方式才决定成败。
  • 可迁移主题：直面矛盾 / 担当作为 / 攻坚克难 / 改革进入深水区 / 基层治理中的历史遗留问题。

示范二｜原句：既为民族做轰轰烈烈的大事，也为群众做实实在在的小事。

  • 我的改写：大事定方向，小事见人心。国之重器、国之大事筑牢的是一个国家的脊梁，而公厕、停车、暖气这些鸡毛蒜皮，决定的是一个普通人对这个国家最真实的感受。两者不是两本账，是一回事。
  • 可迁移主题：政绩观 / 以人民为中心 / 公共服务 / 基层治理精细化 / 青年干部到基层去。

三、人民时评精读▾

精读一《在升级中扩容，在转型中提质》（人民时评）

  • 链接：https://opinion.people.com.cn/n1/2026/1013/c461529-40813227.html
  • 作者：王一鸣 ｜ 系列篇章《——正确认识中国经济的阶段特征与长远趋势②》｜《人民日报》2026-10-13 第 05 版

核心论点：中国消费不是“熄火”，而是处在从生存型向发展型、品质型跃迁的关键阶段，要在升级中扩容、在转型中提质。

结构拆解

  • 提出问题：由国庆文旅消费的热气腾腾切入，直接摆出争议——“今年以来我国消费呈现规模扩张放缓的特征，中国消费增长慢下来了吗？还有挖潜空间吗？”
  • 分析问题：用三层辩证展开——从规模看（增速放缓但增量可观，前 8 个月近 33 万亿元、增 3600 多亿元）；从结构看（商品消费品质化、消费结构服务化、消费方式网络化，服务零售 +4.9%）；从趋势看（AI 终端、智能家居 8000 亿元等新增长点涌现）。并点明“消费是收入和财富的函数”，把问题从消费端推到收入端与预期端。
  • 解决问题：三句话三个动词——增收入让人能消费（城乡居民增收计划）、稳预期让人敢消费（提高公共服务支出比重，投资于物与投资于人结合）、强政策让人愿消费（1000 亿元专项资金 + 贴息 + 消费环境）。

可迁移论证句式

  • “今年前 8 个月消费增速低于去年同期，既有消费品以旧换新政策边际效应递减的因素，也有国际能源市场波动等因素，这更多是短期影响。”
  • “既要看……的压力，更要看……释放的潜力。”（原文：既要化解动能转换带来的压力，更要看到结构优化释放的潜力）
  • “以◯◯为例，当下，◯◯持续受到消费者欢迎；今年我国◯◯市场规模预计将突破◯◯亿元。”（原文用于智能家居，可直接换成本省产业数据）

可套用主题：扩大内需 / 新业态新动能 / 辩证看待经济形势 / 以人民为中心的发展思想 / 做强国内大循环

  • 链接：https://paper.people.com.cn/rmrb/pc/content/202610/13/content_30185257.html
  • 作者：常 晋 ｜《人民日报》2026-10-13 第 04 版

核心论点：发展从来不是一马平川，而是在闯关夺隘中不断向前；时代出题、人民阅卷，问题清单终要靠担当与实干变成精彩答卷。

结构拆解

  • 提出问题：以“中国新能源跑出四个‘全球第一’”的热议起笔，追问这串“第一”从何而来——10 多年前还是技术、设备、市场“三头在外”。

  • 解决问题：从“怎么看”落到“怎么办”——问题在哪里，考场就在哪里；痛点在哪里，发力点就在哪里。再按领域拆解：科技创新“产业出题、科技答题”，改革攻坚敢动奶酪、善疏堵点，民生改善紧盯群众所忧所盼。
