② 转化（5 分钟 · 把别人的话变成自己的）

示范一

  • 原句：全国各地资源禀赋不同，只有因地制宜、扬长避短，方能找到高质量发展的持续发力点。这其中，检验的是发展观，也是政绩观。
  • 我的改写：一个地方的发展没有标准答案，只有适配答案。别人的赛道照抄过来，往往是水土不服；把自己的长板做长，才谈得上竞争力。看一个干部有没有真本事，不看他上了多少项目，而看他上的是不是这块地该上的项目。
  • 可迁移主题：因地制宜 / 正确政绩观 / 防止"一哄而上" / 区域协调发展 / 县域经济 / 新质生产力

示范二

  • 原句：绿色，不是发展的"选答题"，而是"必答题"。
  • 我的改写：过去有人把环保当成"发展之后再补的一课"，把治污看成给增长让路的成本。事实恰恰相反：今天的企业比的是"含绿量"，今天的地区比的是生态本底。"必答题"的意思是——不做就没有分数，而不是做完再补交。

三、人民时评精读▾

精读一：《"苍凉草原"变"智算热土"的启示》（人民论坛）

  • 作者 / 版面：张 凡；《人民日报》2026年10月18日 04 版
  • 链接：https://opinion.people.com.cn/n1/2026/1018/c461529-40816651.html

核心论点（一句话）：乌兰察布把气候寒凉、风电光伏富集这些"先天不足"转化为算力产业的"得天独厚"，证明"绿水青山就是金山银山"不是选择题，而是方法论——因地制宜就能把短板变跳板。

结构拆解（提出问题—分析问题—解决问题）

  • 提出问题：一座"苍凉草原"上的小城，为什么能变成全国乃至全球瞩目的"智算热土"？
  • 分析问题：作者从三个维度层层展开——
  • 从治理角度看：解决生态环境问题，绿色低碳发展是治本之策；协同推进降碳、减污、扩绿、增长，才能筑牢生态安全屏障。
  • 从发展维度看：绿色是生态底色，也是发展亮色。江西上饶"候鸟经济"、四川宜宾"酒都"变"锂都"、新疆洛浦"光伏＋农业"三个案例佐证"新质生产力本身就是绿色生产力"。
  • 从民生需求看：良好生态环境是最普惠的民生福祉，守护绿水青山就是守护人民健康。
  • 解决问题：绿色不是"选答题"而是"必答题"。生态环境法典今年 8 月 15 日施行、专设绿色低碳发展编，以法治手段推动全面绿色转型；发展新质生产力关键在"因地制宜"——漠河把"冷资源"变"热产业"、中卫打造"绿色算力之都"，都是"立足自身条件、发挥比较优势"的注脚。

可迁移论证句式

  1. "从治理角度看……从发展维度看……从民生需求看……"——三段式并列分析，任何"为什么要做 X"的题目都能直接套框架。
  2. "提升产业'含绿量'，也是在锻造发展'含新量''含金量'。"——一字之差的递进对仗，适合做分论点收尾句。
  3. "一度是发展的短板……换个视角，这些'先天不足'恰是……的'得天独厚'。"——反转式论证，写"劣势转化""错位发展"时极好用。

可套用主题方向：绿色发展 / 因地制宜发展新质生产力 / 生态优先 / 绿水青山就是金山银山 / 人与自然和谐共生

精读二：《从乌兰察布转型记，感悟"统筹区域发展"之道》（一见）

  • 作者 / 版面：本报记者 韩 鑫；《人民日报》2026年10月18日 02 版
  • 链接：https://politics.people.com.cn/n1/2026/1018/c461001-40816636.html

核心论点（一句话）：乌兰察布用 2.1 毫秒的时延连接北京，跑出的不只是算力速度，更是"在全国大局中找准自身定位"的区域协调发展辩证法。

结构拆解

  • 提出问题（以小见大）：从乌兰察布到北京，高铁约 100 分钟，借大容量光缆单向时延仅 2.1 毫秒，数据跨越 240 多公里。一座昔日产业选择有限的小城，何以蝶变出圈？
  • 分析问题（两组关系）：
  • 把握一域与全局——"尺有所短、寸有所长"，坚持全国一盘棋思想，在全国发展大局中明确自我发展定位。横向铺开：京津冀、长三角、粤港澳三大动力源；长江经济带共抓大保护、不搞大开发。
  • 立足当下与未来——因地制宜发展新质生产力。算力网是国家"六张网"之一，"东数西算"八大枢纽定位各异：贵州主打数据储存、甘肃承接离线任务、内蒙古锚定低时延算力服务，集群内部错位发展。
  • 再补一个同韵脚的案例：浙江义乌不临海不临边，凭"鸡毛换糖"长成"买全球、卖全球"的世界超市，被称为"因地制宜发展县域经济的成功实践"。
  • 解决问题：日前《中共中央 国务院关于发展新质生产力的意见》公开发布，"因地制宜、先立后破"导向明确；各地立足禀赋、各扬所长，"统筹区域发展"就有了坚实的产业支撑（延安苹果、黑龙江冰雪、青海盐湖三例）。
