② 转化 5 分钟（挑 2 句，把别人的话变成自己的）

示范一

  • 原句：治理成效不是指标报表，百姓烟火才是最终答卷。
  • 我的改写：评价一项工作干得好不好，不能只盯着报表上的数字，要看老百姓的日子有没有真的好过一点。数字是给上面看的，烟火是给百姓过的。
  • 可迁移到：政绩观 / 基层治理 / 公共服务评价 / 反对形式主义 / 调查研究

示范二

  • 原句：从接诉即办到未诉先办，从被动处置到主动治理，从解决一个诉求到实现一片善治。
  • 我的改写：治理有三个台阶——群众找上门才办，是被动；问题还没冒头就先办，是主动；办一件事顺带解决一类事，才是善治。城市治理的升级，就是从"接得住"走向"想得到"、再走向"治得透"。
  • 可迁移到：城市治理 / 数字政府 / 网格化管理 / 风险防控 / 前瞻性谋划

三、人民时评精读▾

① 《一根热线，串起治理新路》（人民时评，李拯）

链接：https://opinion.people.com.cn/n1/2026/1029/c461529-40823499.html
（《人民日报》2026年10月29日 05 版）

核心论点（一句话）：北京 12345 热线以"精细、智慧、韧性"三个关键词，把市民诉求转化为治理任务，走出一条中国特色城市现代化新路子。

结构拆解

  • 提出问题：在北京遇到烦心事怎么办？连外国游客都知道拨打 12345——热线已成为"城市治理总客服"，但如何让一根热线承载超大城市治理？
  • 分析问题：分三层展开——精细（精准回应千差万别的群众诉求，治理成效看百姓烟火）、智慧（从"诉求接收端口"升级为"联结多方资源的智慧中枢"）、韧性（建立人、地、事、物、组织、时间多维标签体系，把风险解决在萌芽状态）。
  • 解决问题：以纪录片《您的声音2》收束——"一根热线，连通城市和人民，连接数智和治理，为城市现代化插上数字翅膀"。

可迁移论证句式

  1. 城市现代化，不能只着眼于宏大，关注高楼大厦和经济总量，更要落脚于微小，回应好千差万别的群众诉求。
  2. 从接诉即办到未诉先办，从被动处置到主动治理，从解决一个诉求到实现一片善治。
  3. 以治理绣花针，串起民生千条线。

可套用主题方向：城市治理现代化 / 数字政府 / 接诉即办与未诉先办 / 超大城市韧性安全 / 以人民为中心的城市工作

② 《"三张桌子"看作风》（评论员观察 · 系列收官篇）

链接：https://opinion.people.com.cn/n1/2026/1029/c461529-40823497.html
（《人民日报》2026年10月29日 05 版）

核心论点（一句话）：餐桌、会议桌、办公桌这三张寻常的桌子，是观察党风政风的窗口——作风之变最终落在干部把精力还给群众、把负担换成实绩。

结构拆解

  • 提出问题：作风无形，但有迹可循。从今年中秋节 68—200 元平价月饼占比超六成切入，"社交货币"回归"食品本位"。
  • 分析问题：三张桌子三条线——餐桌（涤荡"舌尖上的歪风"，湖南郴州食堂扫码付费、宁夏石嘴山电子公函带"时间戳"）、会议桌（从会场搬到现场，贵州独山县阳地村院坝会）、办公桌（减负担增实绩，云南红河 600 多名干部当一天骑手、跟一天网约车）。
  • 解决问题：以"党的作风正，人民心气顺"收束，落到"以好的作风振奋精神、激发斗志、树立形象、赢得民心"。

可迁移论证句式

  1. 作风无形，但有迹可循。
  2. 管住会议的"形"，做实服务的"效"。
  3. 减负，是为了赋能。

可套用主题方向：作风建设 / 为基层减负 / 会议与文风 / 党群关系 / 全面从严治党

【基础题 · 归纳概括】（15 分钟）

题目：给定资料介绍了北京、雄安等地依托 12345 热线推进城市治理的做法。请概括"一根热线"提升城市治理效能的主要经验。
要求：全面、准确，条理清晰，不超过 250 字。

作答思路要点

  1. 精细回应：把热线做成"城市治理总客服"，大事小事一网受理；治理成效看百姓烟火，不看指标报表。
  2. 数智赋能：与大数据、人工智能结合，由"诉求接收端口"升级为"智慧中枢"；用数据流动打通部门分割，形成治理合力。
  3. 未诉先办：对海量诉求做大数据分析，从接诉即办走向未诉先办、主动治理，实现一个诉求到一片善治的跃升。
  4. 韧性安全：建立人、地、事、物、组织、时间多维标签体系，对高风险诉求自动分类研判，把风险解决在萌芽状态。
  5. 多元共治：吸纳多元力量担任兼职网格员，把政府感知与市民感受结合，提升超大城市抗风险能力。

成文模板句：经验可归纳为"精细、智慧、韧性"六个字——以精准回应把诉求办实，以数智赋能把部门打通，以风险研判把隐患前置。

🎯 贵州省情专场加练（最近一场笔试在 30 天内，必做）

题目：有人说，"后发地区搞新质生产力，没有先发优势就只能跟随"。请结合贵州实践，谈谈对这句话的看法。（400 字左右）

作答思路要点

  1. 亮明观点：这种看法是片面的。新质生产力没有标准答案、固定模式，关键在思路，不在起点。
  2. 贵州反证：依托全国首个大数据综合试验区积淀，创新"东数西算""东数西训""东数西渲"模式，让算力从闲置"仓库"变产能"车间"；聚焦 24 个重点行业打造 196 个人工智能典型应用场景，不是"拿着锤子找钉子"，而是应用牵引解决具体痛点。
  3. 战略支撑：守好发展和生态两条底线，强化比较优势推进算力产业扩规模、提能级、增效益；"四个大抓"＋"五个聚焦"，围绕"四新"主攻"四化"。
  4. 升华：后发地区的出路在把比较优势做成不可替代，在因地制宜中走出人无我有的路径，而不是复制粘贴、一哄而上。

可套金句：

  • 打破"捡到篮里都是菜"的思维，善于在大局中找准定位，方能构筑起产业发展优势。
  • 特色就是潜力、竞争力。扬长避短，后发地区、传统产业同样可以发掘人无我有的独特发展路径。
  • "内卷"没有出路，与其盲目跟风，不如精准谋划、精准施策、精准发力。
