② 转化 5 分钟（挑 2 句，把别人的话变成自己的）

示范一：「发展是政绩、安全也是政绩。」

  • 原句：发展是政绩、安全也是政绩。
  • 我的改写：政绩不是单选题。GDP 上去了，事故也跟着上去，这样的政绩经不起检验；把风险挡在群众前面，把底线守在隐患之前，同样是在创造政绩，而且是更经得起历史和人民检验的政绩。
  • 可迁移到：统筹发展和安全 / 正确政绩观 / 底线思维 / 应急管理 / 安全生产 / 防范化解重大风险 / 基层治理中的"防未病"。

示范二：「大国重器的高度，取决于技能人才的高度。」

  • 原句：大国重器的高度，取决于技能人才的高度。
  • 我的改写：一台盾构机的掘进深度，藏着一名焊工的手稳不稳；一枚火箭的入轨精度，藏着一名装配工的毫厘之心。制造业的高度从来不是图纸画出来的，是无数双精益求精的手托起来的。
  • 可迁移到：技能人才 / 工匠精神 / 职业教育 / 人才强国 / 制造强国 / 新质生产力的人才底座 / 破除"重学历轻技能"。

"提出问题—分析问题—解决问题"结构拆解

环节内容

分析问题分两层论证价值：新场景让创新"破土成林"（生产侧），新场景让市场活力"奔涌成潮"（需求侧）

  • "以新需求牵引新供给，让企业看得清市场、摸准需求；以新供给创造新需求……让供需两端在场景中双向奔赴。"（供需双向论证）
  • "沃土方能育良种，开放方能聚动能。"（对仗短句，收尾有力）

  1. 补充制度层面两条（原文"解决问题"部分，写全不丢点）：

  1. 成文规范：用"一是……二是……"或分条标号，每条"动词 + 宾语"，动词用"依托/开放/举办/统筹/建立/健全"，避免抒情句。
