先听后抄 · 四条操作卡（前 20 分钟怎么用，逐条照做）

  1. 点听：每条金句左侧页面都有「听」按钮，抄之前先点一遍听标准读音。耳朵只抓三样——句子在哪儿换气、哪个词被重读、结尾是上扬还是收住。①-1「在纪律上'管住身心'，在事业上'放开手脚'」两句中间必须停半拍，一口气读到底就把"纪律／事业""管住／放开"这两组对照读废了；①-11「安全无小事，防线无盲区」八个字两顿，重音落在"无"字上，读轻了就丢了全称判断的力度。
  2. 跟读：暂停后不看字、只凭耳朵复述一遍。复述不出来的那半句，就是这条还没进脑子的部分，单独再听一次。18 条里带"不是…而是…""只有…才…""不能只…还要…""越…越…"骨架的（①-2、①-3、①-10、①-17、①-18）优先跟读，这类句子考场上是分论点，读顺了才写得出。
  3. 落笔：大字照录原句、不改写，页边小字只写 2—4 个题眼词（见下方逐条精讲）。每抄完一条，先默念一遍"我能放进哪道题的哪一段"，再翻下一条。抄写不是复印，是给每句找一个去处。
  4. 回听：18 条抄完，从 ①-1、①-6、①-11、①-17 里挑 4 条再各听一遍，对照自己抄的字查漏字、查骨架有没有抄反（最容易把"端牢饭碗，靠的是平时把基础打实，而不是临渴掘井、临时找粮"抄成"要重视储备"，把"不是…而是…"的辨析抄丢）。改写不许换掉原句的逻辑骨架，只换场景和措辞——这条在 ② 转化里还要再验一次。

  • 遇"生态"二字先想适用场景（复盘脚本按大类归并时最容易翻车的一处）：①-6「涵养生态，重在清除'板结'，培厚适宜新动能茁壮成长的沃土」讲的是创新生态，归 创新·人才·教育，不能因为有"生态"二字就归生态文明；①-9／①-10 才是真讲国土绿化与流域系统治理，归 生态文明·绿色发展。反过来，①-11「安全无小事，防线无盲区」出自网络安全评论，讲的是安全责任全覆盖，归 治理·法治·安全，不要因为"防线"像生态词就归生态；①-7 有"粮食"但落点在"抓发展"，归 高质量发展·产业；①-18 有"创新"但落点在"统筹"与"治理者答卷"，归 方法论·万能句。判断口径只有一条：看这句话能放进哪道题、论证什么观点，不看字面关键词。

抄写顺序建议：先抄 9 大类的"短句"（①-4 ①-5 ①-7 ①-11 ①-13 ①-14 ①-15，12 字上下、最好背），再抄"长句"（①-1 ①-2 ①-3 ①-6 ①-8 ①-9 ①-10 ①-12 ①-16 ①-17 ①-18，带对偶或辨析、适合做分论点）。每抄完一类，在页边写一个能套的题眼词——政绩观写"管住身心／放开手脚、常长严实深细"，为民写"好看／好用、规则／暖意"，创新写"攻得出用得上／清除板结"，产业写"抓粮食就是抓发展／科技产业携手"，生态写"国土绿化草畜平衡／上下游左右岸共治"，治理写"防线无盲区／业务延伸到哪里"，文化写"扎根民间现场／经济情感文化三连"，开放写"世界眼光／团结一切力量"，方法论写"打实基础不临渴掘井／统筹创新与风险"。

【逐条精讲】18 条抄完立刻对一遍（这是"做精"的一步）

①-1｜在纪律上"管住身心"，在事业上"放开手脚"。（政绩观·党性修养｜担当）

  • 题眼：严管 / 放开
  • 可套主题：全面从严治党与担当作为、严管厚爱结合、容错纠错、干部队伍建设、破除"洗碗效应"
  • 变形说法：「守得住底线，才敢闯得出新路」；配 11/12 评论员观察"法规制度是'紧箍咒'，更是'护身符'"连成一组，一个讲纪律、一个讲制度功能
  • 误用提醒：讲的是严管与担当的辩证统一，不是"放松监管"；单用前半句会被读成只讲约束，必须两句一起抄

①-2｜始终利剑高悬，在常和长、严和实、深和细上下功夫，才能管出习惯、抓出成效。（政绩观·党性修养｜廉洁作风）

  • 题眼：常长严实深细
  • 可套主题：作风建设永远在路上、中央八项规定精神、纠治"四风"、基层减负与长效机制
  • 变形说法：「作风建设不在一时一阵，而在常长二字」；三组对仗词可直接做分论点小标题
  • 误用提醒：这是过程方法论，不要当"反腐成绩"用；写"不敢腐不能腐不想腐"要另配制度句

①-3｜公共空间不能只有"好看"的面子，还要有"好用"的里子。（为民·民生·基层｜公共服务）

  • 题眼：面子 / 里子
  • 可套主题：城市更新、完整社区建设、公共空间供给、反对"重景观轻实用"、民生工程实效
  • 变形说法：「评价公共设施，尺子不在效果图上，在群众歇脚的那张长椅上」；配 11/12 大家谈"把功夫下在'微空间'上"连成一组
  • 误用提醒：讲的是供给导向，不是"反对美观"；写"城市品质"要补"小而美"的具体载体

①-4｜规则可以立，暖意不应少。（为民·民生·基层｜群众工作）

  • 题眼：规则 / 暖意
  • 可套主题：柔性执法、营商环境与人文关怀、消费入座争议、基层协商、公共服务弹性
  • 变形说法：「立规矩不等于冷冰冰，留余地不等于没原则」；适合做"管理与服务"类辩证段的首句
  • 误用提醒：极短，必须紧跟一个具体做法才有说服力（如 15 分钟免费停车、户外劳动者驿站），单独放会显得空

①-5｜攻得出，更要用得上。（创新·人才·教育｜科技创新）

  • 题眼：研用对接
  • 可套主题：科技成果转化、产学研融合、"死亡之谷"、产业链出题实验室答题、新质生产力
  • 变形说法：「实验室里的样品，要变成生产线上的产品」；配 11/12 现场评论"跳出'先出成果再谋转化'"连成一组
  • 误用提醒：讲的是从研发到应用的跃迁，不是"加大研发投入"；写投入要另配"熬得住，才能走得远"那类资本句（本期未选，可在精读里取用）

①-6｜涵养生态，重在清除"板结"，培厚适宜新动能茁壮成长的沃土。（创新·人才·教育｜科研生态）

  • 题眼：板结 / 沃土
  • 可套主题：科技创新与产业创新深度融合、破除体制机制障碍、场景开放、创新生态、人才评价改革
  • 变形说法：「把堵点松开了，新动能自己会长出来」；配《中共中央国务院关于发展新质生产力的意见》"营造有利于科技创新和产业创新深度融合的良好发展生态"用
  • 误用提醒：本期最容易被归错类的一条——"生态"指创新生态，归创新·人才·教育；写生态文明题时不要引用它

①-7｜抓粮食，本身就是抓发展。（高质量发展·产业｜产业培育）

  • 题眼：粮食 / 发展
  • 可套主题：粮食安全与高质量发展、农业现代化、县域经济、扩大内需、产业链增值
  • 变形说法：「稳住产量是底线，拉长链条是增量」；配 11/12 人民时评"农业成为扩大内需、带动县域经济发展的新增长点"用
  • 误用提醒：讲的是把粮食当产业看，不是单纯"保产量"；写耕地红线要另配底线句（①-17）

①-8｜让科技与产业更好携手，高质量发展动能将更加澎湃。（高质量发展·产业｜新质生产力）

  • 题眼：科技 / 产业
  • 可套主题：新质生产力、科技创新与产业创新深度融合、现代化产业体系、场景创新
  • 变形说法：「把'两张皮'缝成'一盘棋'」；适合做结尾上高度句
  • 误用提醒：偏结论句，前面必须有做法支撑（场景办、中试平台、概念验证中心），别当论据用

①-9｜科学开展大规模国土绿化，严格落实草原禁牧休牧和草畜平衡制度。（生态文明·绿色发展｜绿色发展）

  • 题眼：国土绿化 / 草畜平衡
  • 可套主题：三北工程、草原生态修复、荒漠化综合防治、制度管护、美丽中国建设
  • 变形说法：「种得下，更要管得住、养得活」；甘肃、青海、内蒙古卷写"草畜平衡"必用
  • 误用提醒：是规划条文式的硬句，适合做对策段，不适合做开头抒情；出处为《美丽甘肃建设"十五五"规划》，写本省题时点明"我省"更贴

①-10｜构建上下游协同、干支流互济、左右岸共治的系统治理格局。（生态文明·绿色发展｜生态文明）

  • 题眼：上下游 / 左右岸
  • 可套主题：流域综合治理、黄河保护治理、河湖长制、联防联控、系统思维
  • 变形说法：「一河之水，不能分段各管各的」；甘肃卷写"扛牢上游责任"是标准接口
  • 误用提醒：讲的是横向协同机制，不是"某一地单方面治理"；别和"属地责任"混用

①-11｜安全无小事，防线无盲区。（治理·法治·安全｜安全观）

  • 题眼：无小事 / 无盲区
  • 可套主题：总体国家安全观、网络安全、安全生产、风险隐患排查、底线思维
  • 变形说法：「风险不会挑'重点业务'才来」；配 11/12 金台锐评"安全防护，从来没有'次要领域'"连成一组
  • 误用提醒：八个字是全称判断，考场上放分论点首句最有力；但后面必须跟一个具体盲区案例（测试服务器、访客登记系统）才不空

①-12｜做到业务延伸到哪里，安全管理就覆盖到哪里。（治理·法治·安全｜监管）

  • 题眼：同步覆盖
  • 可套主题：数据安全责任制、平台监管、新业态监管、关口前移、源头治理
  • 变形说法：「新业务上线之日，就是责任上线之时」；适合做"监管跟不上创新"类题的对策句
  • 误用提醒：讲责任边界随业务扩展，和①-11 是"判断＋做法"的配套句，建议连背

①-13｜曲艺的生命力永远扎根民间现场。（文化·精神·文明｜传统文化）

  • 题眼：民间现场
  • 可套主题：非遗保护、以人民为中心的创作导向、文化下乡、守正创新、公共文化服务
  • 变形说法：「非遗不能只活在申报书和节庆舞台上」；配 11/12 20 版"守正创新、扎根烟火"用
  • 误用提醒：讲的是创作与生存土壤，不是"加大财政投入"；写扶持政策要另配"从点火者到托底者再到守护者"的角色递进

①-14｜经济连一起，情感融一起，文化更相通。（文化·精神·文明｜精神文明）

  • 题眼：三连递进
  • 可套主题：铸牢中华民族共同体意识、民族团结进步、共同富裕与交往交流交融、互嵌式社区
  • 变形说法：「一起上班、一起吃饭，日子过到一处，心才贴得近」；配 11/12 云南万景社区、景迈山古茶林案例用
  • 误用提醒：是递进关系不是并列，写的时候按"经济—情感—文化"顺序展开，别打乱

①-15｜始终以世界眼光关注人类前途命运。（开放·合作·全球治理｜全球治理）

  • 题眼：世界眼光
  • 可套主题：人类命运共同体、四大全球倡议、大国外交、全球治理观、文明互鉴
  • 变形说法：「把中国的事放进世界的大格局里看」；适合做开放类大作文的收束句
  • 误用提醒：偏立场句，要配具体倡议或行动（COP31、一带一路智库报告）才落地

①-16｜团结一切可以团结的力量，调动一切可以调动的积极因素。（开放·合作·全球治理｜团结合作）

  • 题眼：大团结大联合
  • 可套主题：爱国统一战线、全过程人民民主、凝聚共识、社会协同、基层共治
  • 变形说法：「把'你我'变成'我们'」；孙中山诞辰160周年讲话原句，写"团结奋斗"题最正
  • 误用提醒：虽出自统战语境，但基层治理题也能用（多元主体参与），别只锁在外交类

①-17｜端牢饭碗，靠的是平时把基础打实，而不是临渴掘井、临时找粮。（方法论·万能句｜辩证思维）

  • 题眼：平时 / 临时
  • 可套主题：底线思维、风险防控、久久为功、基础能力建设、应急管理与常态治理
  • 变形说法：「真功夫在没出事的时候」；配 11/12 人民时评"一条沟渠，能掂量出未雨绸缪的分量"用
  • 误用提醒：核心是"不是…而是…"的辨析，改写时千万别把后半句丢掉，丢了就变成一句空话

①-18｜统筹好鼓励创新与防范风险，在规则、制度、标准等方面及时跟上，是治理者需要答好的考题。（方法论·万能句｜系统思维）

  • 题眼：统筹 / 及时跟上
  • 可套主题：包容审慎监管、新业态治理、人工智能伦理、制度供给与创新节奏匹配
  • 变形说法：「既不能一管就死，也不能一放就乱，功夫在'及时'二字」；适合做"发展与规范"类题的总论点
  • 误用提醒：落点是治理者的答题责任，不是单讲创新或单讲风险，两句都要照应

精读一 · 《把丰收的底气攒得更足（人民时评）》

  • 标题与链接：《人民日报》2026年11月12日 第 05 版，常钦， https://paper.people.com.cn/rmrb/pc/content/202611/12/content_30190820.html
  • 核心论点一句话：粮食连年丰收仍要年年抓紧，因为丰收背后有不确定性、有高质量发展的空间、有民生账本的关切，必须把产能基础、发展空间、农民收益三者一起夯实。
  • "提出问题—分析问题—解决问题"结构拆解：
  • 提出问题（第 1—2 段）：先铺"丰"景（沃野千里、麦浪翻滚、秋粮收获稳步推进，夏粮首破 3000 亿斤），紧接一问——"粮食连年丰收，为何还要年年抓紧？"并预告三个答案："应对不确定性的考量、高质量发展的谋划、民生账本的关切"。开头不喊口号，用成绩反设问，这是人民时评最稳的起手式。
  • 分析问题（第 3—8 段）：三段并列，每段一个维度＋一个具象落点。底线维度讲"误了农时难以补回，地力受损难以速复"，用湖北宜城高康村高标准农田"打开闸门就能顺畅排水"的一条沟渠做证；发展维度讲良种良法、社会化服务、加工仓储物流让"一粒粮食在产业链上不断增值"；民生维度讲农资人工成本与天气市场风险，落到"钱等粮"而非"粮等钱"、优粮优价、联农带农。三段各用一个"从…维度看"领起，是归纳概括题的现成答案框架。
  • 解决问题（第 9—10 段）：引总书记"保障粮食等重要农产品稳定供给是农业生产的重中之重"，收束为"把产能基础夯得更实，把发展空间拓得更宽，把农民收益护得更好"三个"更"字排比。
  • 可迁移论证句式：
  1. 「从底线维度看…／从发展维度看…／从民生维度看…」——任何"为什么还要常抓不懈"类题的万能三分法。
  2. 「越是…，越要看清…背后的不确定性」——写风险防控、安全生产、网络安全都可直接换词。
  3. 「看似寻常的…，关键时刻就是…的'压舱石'」——把小案例接大判断的过渡句。
