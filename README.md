# 每日计划（定选备考 PWA）

手机端每日计划时间轴：进度环、整体备考进度、逐时段打卡与反馈、休息/喝水提醒。
数据只存在手机本地（localStorage），不上传任何服务器。

## 手机上的使用方式（关键）

1. 用 **手机系统浏览器**（Chrome / Edge / 夸克 / 三星浏览器）打开 Pages 链接，**不要从 WorkBuddy 里打开**。
2. 菜单 →「添加到主屏幕 / 添加到桌面」。
3. 从桌面图标进入，就是全屏的计划页，不再经过 WorkBuddy。

## 更新每日计划

- 在页面上点底部「导入」，把 WorkBuddy 生成的 Markdown 计划表粘进去即可，整页自动替换。
- 晚上点「生成反馈」导出 Markdown，发回 WorkBuddy 作为次日排计划依据。

## 本地改代码后重新发布

在本目录双击「一键上传.bat」，输入同一个仓库地址，push 完 GitHub Pages 会在 1-2 分钟内自动更新。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| index.html | 全部页面与逻辑（内嵌 CSS/JS，含 9.23 计划样例） |
| manifest.webmanifest | PWA 配置（名称、图标、全屏） |

| icon-192/512/180.png | 桌面图标 |
| .nojekyll | 关闭 Jekyll，防止 GitHub 改动文件 |
